# Clothify 15min

A polished frontend concept for a quick-commerce fashion app: **Clothify — Fresh fits in 15 minutes.**

## Run

```bash
npm install
npm run dev
```

## Included
- Responsive fashion storefront UI
- 15-minute delivery positioning
- Search and category filters
- Wishlist interaction
- Functional shopping bag drawer with subtotal
- Mobile responsive layout
- Premium editorial visual direction
